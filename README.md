# 📚 Advanced Student Management Dashboard System 🎓

💻 A modern high-performance and responsive Student Management System built using ⚛️ React ⚡ Vite and 🎨 Tailwind CSS with a premium 🌌 dark glassmorphic UI design.

## ✨ Features

### 📝 Core CRUD Operations

#### ➕ Add Student
🧾 Quick enrollment with complete student profile creation.

#### ✏️ Edit Student
🛠 Smooth editing of existing student records with pre-filled form fields.

#### 🗑 Delete Student
🔒 Safe deletion system with confirmation modal to prevent accidental data loss.

## 📋 Student Profile Fields

### 👤 Full Name
✅ Validated input length between 3 to 50 characters.

### 🆔 Roll Number
🔐 Unique identifier supporting only alphanumeric characters and hyphens.

### 🏢 Department

💻 Computer Science  
📡 Electronics  
⚙ Mechanical  
🏗 Civil  
⚡ Electrical

### 📅 Academic Year

1️⃣ 1st Year

3️⃣ 3rd Year  
4️⃣ 4th Year

### 📧 Email Address
✅ Real-time email format validation.

### 📞 Phone Number
🔢 Exactly 10 digit validation support.

### 🎂 Date Of Birth
📅 Supports DD MM YYYY format.

### ⚥ Gender

👦 Male  
👧 Female

## 🔒 Advanced Form Validation & UX Improvements

### 🚫 No Empty Fields
⛔ Complete submission blocking for empty inputs.

### 🆔 Unique Roll Number Validation
🚨 Prevents duplicate roll numbers automatically.

### 📧 Unique Email Validation
🚨 Blocks duplicate email addresses in real time.

### 🎂 Age Restriction Validation
🔞 Students must be 17+ years old.

### ↕ Smart Gap Layout
📏 Uses gap-y-14 spacing to avoid overlapping error badges.

### 👀 Better Error UI
💬 Clean text-[12px] validation messages with padded wrappers.

## 🔍 Search Filter & Analytics

### 🔎 Live Search
⚡ Instant search by student name or roll number.

📈 Visual statistics cards showing total students and department distribution.
